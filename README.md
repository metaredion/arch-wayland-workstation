## Overview

A tailored, distraction-free Linux engineering workstation designed for speed, keyboard-only navigation, and frictionless multi-device software development between desktop and laptop machines.

## Key Outcomes & Capabilities

- **Zero-Mouse Tiling Workflow:** Organizes windows automatically across dedicated task workspaces (**Networking**, **Coding**, **AI**, and **Testing**) with instant keyboard focus, resizing, and full dock navigation.
- **Minimal Split Status Bar & Auto-Hiding Dock:** Combines a clean top system status strip (with on-demand live performance metrics) and a sleek auto-hiding bottom dock that stays out of the way while coding.
- **Instant Cross-Machine Local Previewing:** Any local development server started on the primary desktop automatically becomes accessible on the laptop as `localhost` within seconds — no manual port forwarding or configuration changes required.
- **Update-Safe Maintenance Tooling:** Includes pre-reboot desktop compatibility checks so rolling system updates stay reliable day after day.
